# JavaScript DSA & Problem-Solving Collection

A structured collection of **JavaScript programs, Data Structures and Algorithms (DSA) problems, and coding interview exercises** covering Arrays, Strings, Numbers, Objects, Patterns, and other programming concepts.

This repository documents my problem-solving practice, with a focus on understanding different approaches, analyzing their efficiency, and identifying better solutions.

## 🎯 Objectives

- Strengthen JavaScript programming and problem-solving skills.
- Practice commonly asked coding interview questions.
- Explore multiple approaches to solving the same problem.
- Understand and compare **Time Complexity (TC)** and **Space Complexity (SC)**.
- Rank solutions based on efficiency, readability, and practical applicability.
- Improve knowledge of Data Structures and Algorithms.
- Maintain an organized reference for future revision and interview preparation.

## 🧠 Problem-Solving Approach

For applicable problems, the solutions include:

**1. Multiple Approaches**

Different techniques are explored, ranging from straightforward implementations to more optimized solutions.

**2. Time Complexity (TC)**

Analysis of how execution time scales with input size using Big O notation.

**3. Space Complexity (SC)**

Analysis of additional memory requirements for each solution.

**4. Solution Rankings**

Approaches are compared and ranked based on:

- Time efficiency
- Space efficiency
- Code readability
- Maintainability
- Practical usage

**5. JavaScript Concepts**

Programs also demonstrate JavaScript features and techniques such as:

- Arrays, Objects, Maps, and Sets
- Loops and built-in array methods
- Recursion
- Two Pointers
- Hashing and frequency counting
- String manipulation
- Other problem-solving techniques

## ⚖️ Complexity Analysis

Solutions are evaluated using standard Big O notation.

| Complexity | Common Interpretation |
|---|---|
| O(1) | Constant |
| O(log n) | Logarithmic |
| O(n) | Linear |
| O(n log n) | Linearithmic |
| O(n²) | Quadratic |
| O(2ⁿ) | Exponential |

**Note:** The most optimized solution is not always the most practical. Readability, maintainability, input constraints, and real-world requirements are also considered when comparing approaches.

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/ankit420420/DSA.git
```

**2. Navigate to the project**

```bash
cd DSA
```

**3. Explore the programs**

Navigate to any topic folder and select a JavaScript file.

**4. Run a program**

```bash
node filename.js
```

Make sure Node.js is installed. Run the command from the directory containing the selected file.
